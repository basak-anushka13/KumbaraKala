# 🏺 KumbaraKala

KumbaraKala is an Android application developed using Kotlin and Firebase Firestore to digitally promote traditional clay products and support local artisans. The application allows users to explore clay products, learn about their benefits, generate personalized benefit cards, and share them through social media platforms.
